# Recetas App (React + Vite + TypeScript + Tailwind + React Router)

## Arranque
```bash
npm i
npm run dev
```

Necesitarás Node.js >= 20.19 o 22.12+.

## Características
- Lista de recetas con tarjetas.
- Filtros por búsqueda, tiempo máximo, dificultad e ingredientes.
- Persistencia de filtros en la URL (query params).
- Favoritos con localStorage (botón ☆/★ en lista y detalle).
- Rutas dinámicas: `/recetas/:slug`.
